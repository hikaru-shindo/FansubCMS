# FansubCMS

[![Scrutinizer Code Quality](https://scrutinizer-ci.com/g/hikaru-shindo/FansubCMS/badges/quality-score.png?b=main)](https://scrutinizer-ci.com/g/hikaru-shindo/FansubCMS/?branch=main)
[![Build Status](https://scrutinizer-ci.com/g/hikaru-shindo/FansubCMS/badges/build.png?b=main)](https://scrutinizer-ci.com/g/hikaru-shindo/FansubCMS/build-status/main)

FansubCMS is a CMS designed for the needs of Fansubbers
and written in PHP with the Zend PHP Framework licensed
under the GNU GPL Version 3 which is enclosed to the repository
in the file LICENSE.

It provides easy management of your fansubs, news and your
group.

Installation instructions can be found in the INSTALL file.
